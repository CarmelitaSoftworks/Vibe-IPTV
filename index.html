Instalar en el TV con Downloader

  1. En el TV, instala la app Downloader (de AFTVnews) desde la tienda de apps (Google Play o Amazon Appstore).
  2. Permite instalar apps desde Downloader: Ajustes → Apps → Acceso especial → Instalar apps desconocidas → Downloader → Permitir. En Fire TV: Mi Fire TV → Opciones para desarrolladores → Instalar apps desconocidas → Downloader.
  3. Abre Downloader y escribe en el recuadro de dirección el código 9370754
    (o la dirección carmelitasoftworks.github.io/Vibe-IPTV/tv).
  4. Pulsa Go: se descarga el APK. Cuando termine, elige Instalar y luego Abrir.
  5. Al final Downloader ofrece borrar el APK: puedes borrarlo para liberar espacio (la app queda instalada).

Guía completa paso a paso y solución de problemas: docs/DOWNLOADER.md · English: docs/DOWNLOADER.en.md

Install on your TV with Downloader

  1. Install Downloader (by AFTVnews) from your TV's app store.
  2. Allow it to install apps: Settings → Apps → Special app access → Install unknown apps → Downloader (Fire TV: My Fire TV → Developer options).
  3. Open Downloader and type the code 9370754 (or carmelitasoftworks.github.io/Vibe-IPTV/tv), then press Go and Install.
